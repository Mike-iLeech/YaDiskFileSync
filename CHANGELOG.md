# Изменения

## [2.0.0]

- Синхронизируется целая папка YaDiskSync, а не один файл, — в обе стороны, как у приложения Яндекс.Диска.
- Папка YaDiskSync в панели навигации Проводника; где она лежит и с какой папкой Диска связана — в окне настроек.
- Доступ ко всему Диску (нужно добавить права приложению на oauth.yandex.ru и войти заново).
- Конфликт: остаётся более новая версия; проигравшая уходит в Корзину (на компьютере — Windows, на Диске — Диска).
- Переход с 1.x: программа предложит скопировать прежний файл в папку YaDiskSync.
- Удаление переносится в Корзину с другой стороны; при массовом удалении — пауза и вопрос.
- Меню «Синхронизация»: «Синхронизировать сейчас» и окно «Статус синхронизации» с процентом и скоростью.
- Окно настроек; пошаговая инструкция входа; установщик YaDiskFileSync-Setup.exe.
- Дневные копии «История» убраны.

## [1.0.0]

- Первая версия: загрузка одного файла на Яндекс.Диск (папка приложения) после каждого сохранения.
- Вход через Яндекс ID по коду подтверждения, токены зашифрованы DPAPI.
- Дневные копии в папке «История», хранятся последние 30 (7–90 в меню).
- Повтор при временных ошибках, значок состояния в трее, автозапуск, автообновление из GitHub Releases.
