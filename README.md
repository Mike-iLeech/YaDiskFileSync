# YaDisk File Sync

Маленькая программа в трее Windows: следит за **одним файлом** (например, книгой Excel с личной бухгалтерией)
и после каждого сохранения загружает его на Яндекс.Диск через официальный REST API.

- Вход через Яндекс ID по коду подтверждения — пароль от Яндекса программа не видит.
- Доступ только к своей папке на Диске: `Приложения/<имя приложения>/`. Остальные файлы Диска программе недоступны.
- На Диске лежат основная копия файла и дневные копии в подпапке `История`
  (`Бухгалтерия 2026-10-22.xlsx`; за день одна копия, хранятся последние 30 дней — меняется в меню).
- Синхронизация в одну сторону: компьютер → Диск. Файл правится только на этом компьютере.
- Нет сети — загрузка повторится сама (через 30 с, 1, 2, 5, 15 минут); пропущенное сохранение догонится при следующем запуске.
- Цвет значка: зелёный — синхронизировано, синий — загрузка, оранжевый — временная ошибка (повторим сами),
  красный — нужно действие (войти, освободить место), серый — файл не выбран.
- Двойной щелчок по значку — синхронизировать сейчас; правая кнопка — меню.

## Установка

1. Скачайте `YaDiskFileSync.exe` со страницы [Releases](https://github.com/Mike-iLeech/YaDiskFileSync/releases/latest)
   и положите в постоянное место, например `%LOCALAPPDATA%\Programs\YaDiskFileSync\`.
2. Нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (x64) — Windows предложит его установить при первом запуске.
3. Запустите. В меню включите «Запускать вместе с Windows».

Программа обновляется сама из релизов этого репозитория (проверка раз в сутки, меняется в меню).

## Регистрация приложения в Яндексе (один раз)

Программа входит в Яндекс от имени **вашего** приложения, поэтому его нужно зарегистрировать:

1. Откройте [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new) под своей учётной записью Яндекса.
2. Название — например, `Бухгалтерия`. **Так будет называться папка** на Диске: `Приложения/Бухгалтерия`.
3. Платформа — «Веб-сервисы», Redirect URI: `https://oauth.yandex.ru/verification_code`.
4. Доступы: раздел «Яндекс.Диск REST API» → **«Доступ к папке приложения на Диске»** (`cloud_api:disk.app_folder`).
   Другие доступы не нужны.
5. Сохраните и скопируйте **ClientID** и **Client secret**.

Затем в программе: «Войти в Яндекс…» → вставьте ClientID и секрет → «Получить код» → откроется страница Яндекса,
введите показанный код и разрешите доступ. После входа выберите файл.

## Где что хранится

- Настройки: `%APPDATA%\YaDiskFileSync\settings.json`.
- Секрет приложения и токены: `%APPDATA%\YaDiskFileSync\secrets.bin`, зашифрованы DPAPI — расшифровать может
  только ваша учётная запись Windows на этом компьютере. «Выйти из Яндекса» удаляет токены;
  отозвать доступ полностью можно на [id.yandex.ru](https://id.yandex.ru/security/apps).

## Сборка

```
dotnet test tests/YaDiskFileSync.Tests.csproj -c Release
dotnet publish YaDiskFileSync.csproj -c Release -o publish
```

Выпуск: поднять `<Version>` в `YaDiskFileSync.csproj`, дописать `CHANGELOG.md`, поставить тег `vX.Y.Z` —
GitHub Actions соберёт EXE и опубликует релиз.
