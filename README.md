# YaDisk File Sync

Программа в трее Windows: синхронизирует **папку YaDiskSync** на компьютере с выбранной папкой на Яндекс.Диске
через официальный REST API — в обе стороны, как приложение Яндекс.Диска.

- Папка `YaDiskSync` появляется в панели навигации Проводника (как «Яндекс.Диск» и OneDrive). Где она лежит
  на компьютере и с какой папкой Диска синхронизируется — выбирается в настройках.
- Синхронизация **двусторонняя**: изменили файл на компьютере — он загружается на Диск через несколько секунд
  после сохранения; изменили на Диске (в браузере, с телефона) — скачивается при следующей проверке
  (раз в минуту, меняется в настройках: 30 с / 1 / 5 / 15 мин).
- **Конфликт** (файл изменили с обеих сторон): остаётся более новая версия. Если проигрывает версия на компьютере,
  она сначала уходит в Корзину Windows; проигравшая версия на Диске остаётся в истории версий Диска.
- **Удаление** переносится в Корзину с другой стороны: удалили на компьютере — файл уходит в Корзину Диска,
  удалили на Диске — в Корзину Windows. Изменение важнее удаления: если файл удалили с одной стороны,
  а с другой успели изменить, он восстанавливается.
- **Защита от массового удаления:** если с одной стороны разом пропало больше половины файлов (отключили диск,
  удалили папку не там) или пропала сама папка на Диске, синхронизация встаёт на паузу и спрашивает:
  удалить и с другой стороны, вернуть файлы или решить позже.
- Временные и служебные файлы не синхронизируются: блокировки Office `~$…`, временные файлы сохранения Excel,
  `*.tmp`, `desktop.ini`, `Thumbs.db`. Недописанная книга Excel не загружается, пока Excel не закончит сохранение.
- Выход из учётной записи не трогает папку: файлы остаются на компьютере, синхронизация просто останавливается.
- Нет сети — повтор сам (через 30 с, 1, 2, 5, 15 минут).
- Цвет значка: зелёный — синхронизировано, синий — идёт синхронизация, оранжевый — временная ошибка
  (повторим сами), красный — нужно действие (войти, решить про удаление, освободить место), серый — не настроено.

Меню по правой кнопке: открыть папку, открыть папку на Диске, **Синхронизация → Синхронизировать сейчас /
Статус синхронизации** (окно со всеми файлами, процентом и скоростью передачи), Настройки, Выход.
Двойной щелчок по значку открывает папку.

## Установка

1. Скачайте `YaDiskFileSync-Setup.exe` со страницы [Releases](https://github.com/Mike-iLeech/YaDiskFileSync/releases/latest)
   и запустите. Права администратора не нужны: программа ставится для вашей учётной записи
   в `%LOCALAPPDATA%\Programs\YaDiskFileSync`, появляется в меню «Пуск» и в «Приложениях и возможностях».
2. Нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (x64) — установщик проверит
   и предложит страницу загрузки.

Программа обновляется сама из релизов этого репозитория (проверка раз в сутки, меняется в настройках).
Удаление — через «Приложения и возможности»; папка YaDiskSync с файлами при этом остаётся.

## Регистрация приложения в Яндексе (один раз)

Программа входит в Яндекс от имени **вашего** приложения Яндекс ID, поэтому его нужно зарегистрировать.
При первом запуске программа показывает эту же инструкцию по шагам.

1. Откройте [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new) под своей учётной записью Яндекса.
2. Название — любое (например, `YaDiskSync`). Платформа — «Веб-сервисы», Redirect URI:
   `https://oauth.yandex.ru/verification_code`.
3. Доступы: раздел «Яндекс.Диск REST API» → отметьте **три** права:
   - «Чтение всего Диска» (`cloud_api:disk.read`),
   - «Запись в любом месте на Диске» (`cloud_api:disk.write`),
   - «Доступ к информации о Диске» (`cloud_api:disk.info`).
4. Сохраните и скопируйте **ClientID** и **Client secret**.

Затем в программе: вставьте ClientID и секрет → «Получить код» → откроется страница Яндекса,
введите показанный код и разрешите доступ. После входа выберите папки в окне настроек.

> Переход с версии 1.x: версия 1 работала только с папкой приложения. Откройте своё приложение
> на oauth.yandex.ru → «Редактировать», добавьте права из шага 3 и войдите в программе заново.

## Где что хранится

- Настройки: `%APPDATA%\YaDiskFileSync\settings.json`; состояние синхронизации — `state.json` там же.
- Секрет приложения и токены: `%APPDATA%\YaDiskFileSync\secrets.bin`, зашифрованы DPAPI — расшифровать может
  только ваша учётная запись Windows на этом компьютере. Отозвать доступ полностью можно на
  [id.yandex.ru](https://id.yandex.ru/security/apps).
- В папке синхронизации — скрытая служебная папка `.yadisksync` (временные файлы скачивания).

## Сборка

```
dotnet test tests/YaDiskFileSync.Tests.csproj -c Release
dotnet publish YaDiskFileSync.csproj -c Release -o publish
iscc /DAppVersion=2.0.0 installer\YaDiskSync.iss
```

Выпуск: поднять `<Version>` в `YaDiskFileSync.csproj`, дописать `CHANGELOG.md`, поставить тег `vX.Y.Z` —
GitHub Actions соберёт EXE и установщик и опубликует релиз.
